# 🕵️‍♂️ SLED-VR: Иммерсивная платформа для обучения навыкам расследования преступлений

**SLED-VR** — это учебная VR-платформа, предназначенная для отработки практических навыков осмотра места происшествия и сбора улик. Проект позволяет будущим следователям погрузиться в реалистичную следственную ситуацию, принять процессуальные решения и получить объективную оценку своих действий без риска для реального учебного процесса.

## 🎯 Ключевые возможности

-   **Иммерсивное погружение:** Полноценная виртуальная реальность на базе Unity и VR-гарнитур.
-   **Реалистичный сценарий:** Расследование убийства со сбором улик на месте происшествия.
-   **Система оценивания:** Автоматический подсчёт баллов в зависимости от правильности сбора улик и составления дела.
-   **Образовательный фокус:** Разработано для ведомственных учебных заведений и курсов повышения квалификации.
